# 🧮 CodeAlpha Pro Calculator

## 📌 Project Title

**CodeAlpha Pro Calculator – Responsive Calculator using HTML, CSS & JavaScript**

## 📌 Project Overview

CodeAlpha Pro Calculator is a modern, responsive, and interactive web-based calculator developed as **Task 1** for the **CodeAlpha Frontend Development Internship**.

The application performs all basic arithmetic operations with a clean and intuitive interface. It supports keyboard input, decimal calculations, percentage operations, clear and delete functions, and provides a seamless user experience across desktop and mobile devices.

---

## 🚀 Features

* 🧮 Modern Calculator Interface
* ➕ Addition (+)
* ➖ Subtraction (−)
* ✖ Multiplication (×)
* ➗ Division (÷)
* 📊 Percentage (%) Support
* 🔢 Decimal Number Support
* ⌨️ Keyboard Support
* 🗑️ Clear (AC) Button
* ⌫ Delete (Backspace) Button
* ⚡ Real-Time Result Display
* 📱 Fully Responsive Design
* 🎨 Modern UI with Smooth Hover Effects

---

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
